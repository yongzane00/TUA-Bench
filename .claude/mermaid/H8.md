# H8 "Cost budget": a spend meter on every turn (`terminus_2_harness8.py`)

The model is told its dollar budget for the task at the start. Every screen update begins with a
spend meter: dollars used and left, tokens used (input / output), how full the context is, and how
many more turns fit at the cost of its recent turns (shaded). Cost is harbor's own per-trial cost,
so helper calls count too. When the budget is spent the loop stops and the machine is graded as it
stands. Starting budget: qwen3.8 $0.048, Qwen3.6 $0.26, the 90th-percentile cost of H0's solved
trials. Kwarg: `cost_budget_usd`; the budget is part of the config name (`harness8-cost0.048-attempt5`).

```mermaid
sequenceDiagram
    autonumber
    participant H as Harness (H8)
    participant C as Container (task env)
    participant M as Main model
    participant G as Grader (tests)

    H->>C: start tmux shell
    rect rgba(227, 73, 72, 0.15)
        H->>M: system prompt + task + "you have $0.048 for this task, every update shows the spend" + first screen
    end
    loop each turn, while spend is below the budget
        M->>H: analysis, plan, keystrokes
        H->>C: type keystrokes, wait
        C-->>H: screen text
        rect rgba(227, 73, 72, 0.15)
            H->>M: "[Cost $0.0150 of $0.0480, $0.0330 left | tokens 182k in / 9.4k out | context 45k of 256k | about 9 turns fit]"<br/>+ screen text
        end
    end
    alt model says done within budget
        M->>H: task_complete = true
        H->>M: "Are you sure?" + screen text
        M->>H: task_complete = true (confirms)
    else budget spent
        Note over H: loop stops, graded as is
    end
    H->>G: run tests on final env
    G-->>H: reward
```
