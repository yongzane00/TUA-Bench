# H7 "Time budget": a clock on every turn (`terminus_2_harness7.py`)

The model is told its time budget at the start (default 2400 s). Every screen update begins with a
clock: time used and time left, how long its last reply took and at what speed (output tokens per
second), and how many more turns fit at its recent pace (shaded). Nothing else changes. When the
budget is used up the loop stops and the machine is graded as it stands. Kwarg: `time_budget_sec`;
the budget is part of the config name (`harness7-time2400-attempt5`).

```mermaid
sequenceDiagram
    autonumber
    participant H as Harness (H7)
    participant C as Container (task env)
    participant M as Main model
    participant G as Grader (tests)

    H->>C: start tmux shell, start the clock
    rect rgba(178, 118, 0, 0.15)
        H->>M: system prompt + task + "you have 2400 s, every update shows the clock" + first screen
    end
    loop each turn, while time is left
        M->>H: analysis, plan, keystrokes
        H->>C: type keystrokes, wait
        C-->>H: screen text
        rect rgba(178, 118, 0, 0.15)
            H->>M: "[Time 1000 of 2400 s, 1400 s left | last reply 41 s at 38 tok/s | about 17 turns fit]"<br/>+ screen text
        end
    end
    alt model says done in time
        M->>H: task_complete = true
        H->>M: "Are you sure?" + screen text
        M->>H: task_complete = true (confirms)
    else time budget used up
        Note over H: loop stops, graded as is
    end
    H->>G: run tests on final env
    G-->>H: reward
```
