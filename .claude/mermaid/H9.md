# H9 "All budget": time and cost together, plus the turn count (`terminus_2_harness9.py`)

H7 and H8 combined. The model is told both budgets at the start. Every screen update shows the turn
number, dollars used of the budget, time used of the budget, last reply speed, tokens used, and how
many turns fit before the tightest budget runs out, and which budget that is (shaded). Turns are
shown, not capped. The loop stops when either time or cost runs out, and the machine is graded as it
stands. Kwargs: `time_budget_sec`, `cost_budget_usd`; both budgets are part of the config name
(`harness9-time2400-cost0.048-attempt5`).

```mermaid
sequenceDiagram
    autonumber
    participant H as Harness (H9)
    participant C as Container (task env)
    participant M as Main model
    participant G as Grader (tests)

    H->>C: start tmux shell, start the clock
    rect rgba(110, 60, 150, 0.15)
        H->>M: system prompt + task + "budgets: 2400 s and $0.048, every update shows both" + first screen
    end
    loop each turn, until time or cost runs out
        M->>H: analysis, plan, keystrokes
        H->>C: type keystrokes, wait
        C-->>H: screen text
        rect rgba(110, 60, 150, 0.15)
            H->>M: "[Turn 14 | cost $0.0150 of $0.0480 | time 1000 of 2400 s<br/>| last reply 41 s at 38 tok/s | tokens 182k in / 9.4k out | about 9 turns fit, cost runs out first]"<br/>+ screen text
        end
    end
    alt model says done within both budgets
        M->>H: task_complete = true
        H->>M: "Are you sure?" + screen text
        M->>H: task_complete = true (confirms)
    else time or cost runs out
        Note over H: loop stops, graded as is
    end
    H->>G: run tests on final env
    G-->>H: reward
```
