# H5 "Snapshot verifier": before/after snapshot + independent verifier (`terminus_2_harness5.py` + `h5_snapshot.py`)

Before the agent starts, a snapshot script records the machine's state: files (with the content of
small text files and the structure of office files), processes, listening ports, browser tabs,
desktop windows and settings, and Python packages. The snapshot is kept on the host, where the
agent cannot change it. When the agent says it is done, the harness takes a second snapshot. A
verifier then judges the task text plus the diff: a separate call to the same model, with no chat
history. PASS sends the trial to grading. FAIL sends the verifier's reasons and the diff back to
the agent, which keeps working. After at most 2 checks the trial is graded regardless. Verifier
tokens are counted in the trial's cost. Logs: `agent/env-before.json`, `env-after-N.json`,
`verifier-checks.json`.

```mermaid
sequenceDiagram
    autonumber
    participant H as Harness (H5)
    participant C as Container (task env)
    participant M as Main model
    participant V as Verifier model (separate call, no history)
    participant G as Grader (tests)

    H->>C: start tmux shell
    H->>C: run snapshot script
    C-->>H: BEFORE snapshot (files, processes, ports, browser, settings)
    Note over H: kept on the host,<br/>agent cannot touch it
    H->>M: system prompt + task + first screen
    loop each turn
        M->>H: analysis, plan, keystrokes
        H->>C: type keystrokes, wait
        C-->>H: screen text
        H->>M: screen text
    end
    M->>H: task_complete = true
    H->>C: run snapshot script again
    C-->>H: AFTER snapshot
    Note over H: diff = BEFORE vs AFTER<br/>(created, modified, deleted,<br/>processes, ports, tabs, settings)
    H->>V: task instruction + diff
    alt verifier: complete
        V-->>H: PASS
        H->>G: run tests on final env
        G-->>H: reward
    else verifier: problem found
        V-->>H: FAIL + reasons
        H->>M: verifier's reasons + diff, "fix it or explain"
        M->>H: keeps working (more turns) ... task_complete again
        Note over H,V: repeat check, at most N rounds,<br/>then grade regardless
    end
```
