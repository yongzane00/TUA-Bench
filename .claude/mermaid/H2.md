# H2: reasoning kept in the history (`interleaved_thinking: true`)

Stock terminus-2 sends back only the model's visible replies from earlier turns and drops their
reasoning. H2 keeps each turn's reasoning in the chat history (shaded), so the model can see why it
did what it did. On Qwen3.6 this also needs `chat_template_kwargs.preserve_thinking: true`;
without it the chat template strips the reasoning anyway. The cost is a much longer prompt on
every turn.

```mermaid
sequenceDiagram
    autonumber
    participant H as Harness (H2)
    participant C as Container (task env)
    participant M as Main model
    participant G as Grader (tests)

    H->>C: start tmux shell
    H->>M: system prompt + task + first screen
    loop each turn
        M->>H: reasoning + analysis, plan, keystrokes
        rect rgba(217, 115, 13, 0.15)
            Note over H: the history keeps the reasoning too<br/>(H0 keeps only the visible reply)
        end
        H->>C: type keystrokes, wait
        C-->>H: screen text
        H->>M: whole history incl. all earlier reasoning + screen text
    end
    M->>H: task_complete = true
    H->>M: "Are you sure?" + screen text
    M->>H: task_complete = true (confirms)
    H->>G: run tests on final env
    G-->>H: reward
```
