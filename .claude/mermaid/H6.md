# H6 "Turn budget": 40 turns, with a counter on every turn (`terminus_2_harness6.py`)

The task text tells the model it has 40 turns, and every screen update starts with
"[Turn N of 40]" (shaded). The model can plan and wrap up in time rather than hitting the time
limit without warning. After turn 40 the loop stops and the environment is graded as it stands.

```mermaid
sequenceDiagram
    autonumber
    participant H as Harness (H6)
    participant C as Container (task env)
    participant M as Main model
    participant G as Grader (tests)

    H->>C: start tmux shell
    rect rgba(76, 138, 28, 0.15)
        H->>M: system prompt + task + "you have 40 turns" + first screen
    end
    loop turn N = 1 to 40
        M->>H: analysis, plan, keystrokes
        H->>C: type keystrokes, wait
        C-->>H: screen text
        rect rgba(76, 138, 28, 0.15)
            H->>M: "[Turn N of 40]" + screen text<br/>("(last turn)" on turn 40)
        end
    end
    alt model says done before turn 40
        M->>H: task_complete = true
        H->>M: "Are you sure?" + screen text
        M->>H: task_complete = true (confirms)
    else all 40 turns used
        Note over H: the loop stops, no more turns
    end
    H->>G: run tests on final env
    G-->>H: reward
```
