# H1: the completion check restates the instruction (`terminus_2_harness1.py`)

Only the "Are you sure?" step changes (shaded). Before it confirms, the model sees the original
task again, so it compares its work with what was asked rather than with what it remembers.

```mermaid
sequenceDiagram
    autonumber
    participant H as Harness (H1)
    participant C as Container (task env)
    participant M as Main model
    participant G as Grader (tests)

    H->>C: start tmux shell
    H->>M: system prompt + task + first screen
    loop each turn
        M->>H: analysis, plan, keystrokes
        H->>C: type keystrokes, wait
        C-->>H: screen text
        H->>M: screen text
    end
    M->>H: task_complete = true
    rect rgba(42, 91, 215, 0.15)
        H->>M: screen text + "Here is the task you were given: (full instruction)<br/>Are you sure what you did follows these instructions?"
    end
    alt model confirms
        M->>H: task_complete = true
        H->>G: run tests on final env
        G-->>H: reward
    else model finds a gap
        M->>H: more keystrokes (back to the turn loop)
    end
```
