# H4: rolling observation window (`terminus_2_harness4.py`)

The prompt keeps only the last 3 terminal outputs word for word. Each older output is replaced by
a short bullet summary written by a separate call to the same model (shaded). The first message
(system prompt, task and first screen) and every model reply stay untouched. Each summary starts
in the background one turn early (prefetch), so the main loop rarely waits. The qwen38 run used
`summary_reasoning_effort: none`.

```mermaid
sequenceDiagram
    autonumber
    participant H as Harness (H4)
    participant C as Container (task env)
    participant M as Main model
    participant S as Summarizer (same model, separate call)
    participant G as Grader (tests)

    H->>C: start tmux shell
    H->>M: system prompt + task + first screen
    loop each turn
        M->>H: analysis, plan, keystrokes
        H->>C: type keystrokes, wait
        C-->>H: screen text
        rect rgba(74, 58, 167, 0.15)
            H->>S: the screen about to leave the window (in the background)
            S-->>H: up to 8 bullets
            Note over H: history = first message + all replies<br/>+ last 3 screens verbatim + older screens as summaries
        end
        H->>M: history + screen text
    end
    M->>H: task_complete = true
    H->>M: "Are you sure?" + screen text
    M->>H: task_complete = true (confirms)
    H->>G: run tests on final env
    G-->>H: reward
```
